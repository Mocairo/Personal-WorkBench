# 05 桌面壳、快捷键切换与全局体验

## 目标

桌面壳负责把多个工作台模块组织成一个稳定的本地应用。它不承载具体业务逻辑，但决定用户如何进入页面、感知系统状态、切换工作上下文和处理全局任务。

本项目的桌面壳不采用固定左侧主导航。主窗口默认只显示当前页面内容，页面切换通过快捷键、临时页面切换器和命令面板完成。切换器只在用户触发时出现，关闭后不占用页面空间。

## 核心交互模型

主窗口采用“当前页面优先”的工作方式：

```text
单主窗口
  -> 当前页面内容全窗口展示
  -> 快捷键触发页面切换器
  -> 页面切换器居中显示候选页面
  -> 用户确认后进入目标页面
  -> 切换器关闭，窗口只保留目标页面内容
```

这种模式参考用户提供的图片：中心是当前选中的页面卡片，周围是其他页面的弱化预览或名称提示。用户可以用快捷键在页面之间移动，也可以点击中心卡片进入页面。

## 应用窗口

主窗口建议采用以下结构：

- 当前页面宿主：承载当前页面，是默认唯一可见的主内容。
- 临时页面切换器：快捷键触发，居中覆盖在当前窗口上，用卡片或横向轮盘展示页面。
- 全局状态条：轻量显示服务状态、当前模型、后台任务和设置入口，可常驻顶部或以悬浮方式出现。
- 任务中心浮层：只在有任务、错误或用户主动打开时出现。
- 详情抽屉：由当前页面自己决定是否打开，不作为全局固定布局。

窗口能力：

- 单主窗口。
- 支持最小化到托盘。
- 支持启动时恢复上次页面。
- 支持打开本地路径选择器。
- 支持从外部链接或文件关联进入指定模块。
- 支持全局快捷键打开页面切换器。
- 支持不显示固定侧边栏的沉浸式页面体验。

## 页面切换方式

### 直接快捷键

建议第一阶段默认快捷键：

- `Alt+1`：Home Dashboard。
- `Alt+2`：Agent Chat。
- `Alt+3`：Knowledge Base。
- `Alt+4`：Agent Management。
- `Alt+5`：Code Repository。
- `Alt+6`：Local Music。
- `Alt+7`：情报中心。
- `Alt+8`：小组件。

这些快捷键应可在设置中修改。若与系统或其他应用冲突，应允许用户禁用或重映射。

### 顺序切换

建议支持：

- `Ctrl+Tab`：切到下一个页面。
- `Ctrl+Shift+Tab`：切到上一个页面。

顺序按页面注册顺序排列。页面顺序默认固定，但后续可以支持用户自定义。

### 页面切换器

建议支持：

- `Alt+Space` 或用户自定义快捷键：打开页面切换器。
- 方向键或鼠标滚轮：移动选中页面。
- `Enter`：进入当前选中页面。
- `Esc`：关闭切换器，不改变当前页面。
- 点击页面卡片：进入对应页面。

页面切换器展示内容：

- 页面名称。
- 页面图标。
- 快捷键提示。
- 简短说明。
- 最近状态，例如未读任务数、服务异常、索引进行中。

切换器出现时可以弱化当前页面背景，但不能销毁当前页面状态。只有确认切换后才进入目标页面。

### 命令面板

建议支持 `Ctrl+K` 打开命令面板。命令面板用于搜索页面、设置项、任务和常用动作。

命令面板与页面切换器不同：

- 页面切换器用于快速切换一级页面。
- 命令面板用于搜索和执行更细的命令。

## 一级页面入口

一级页面仍保持 8 个：

- Home Dashboard：全局概览。
- Agent Chat：对话和任务执行。
- Knowledge Base：知识资料和 RAG。
- Agent Management：Agent 配置、工具权限和执行历史。
- Code Repository：本地代码仓库。
- Local Music：本地音乐。
- 情报中心：local-intel 接入。
- 小组件：轻量工具集合。

这些入口不常驻在左侧导航中，而是注册到 Page Registry，由快捷键、页面切换器和命令面板调用。

每个页面内部可以有自己的二级标签、左栏、文件树或详情抽屉。例如 Code Repository 页面内部可以显示项目文件树，但那是页面内部布局，不是全局桌面壳导航。

## 页面状态保留

页面切换时需要明确状态策略：

- 当前页面可以保留滚动位置、筛选条件、选中对象和临时输入。
- 长时间未访问的页面可以被挂起以节省资源。
- 后台任务不依赖页面是否显示。
- Agent Chat 的流式输出和任务执行在切换页面后仍继续。
- 切回页面时恢复上次状态。

页面状态应写入 App State Store 或页面内部缓存，不能依赖 DOM 是否仍挂载。

## 全局搜索

全局搜索应支持跨模块检索，但第一阶段只定义检索来源和结果类型。

检索来源：

- 知识库文档标题、标签、正文片段。
- 代码仓库名称、文件路径、符号、Git 提交。
- 情报条目标题、来源、标签。
- Agent 会话标题、任务日志。
- 音乐标题、艺术家、专辑。

结果类型：

- 文档。
- 代码文件。
- 代码符号。
- 情报条目。
- Agent 会话。
- 音乐曲目。
- 设置项。

全局搜索不直接执行危险操作，只负责导航或打开预览。

## 全局状态

全局状态条应保持轻量，避免把桌面壳变成复杂控制面板。

建议展示：

- local-intel 服务：运行中、未运行、异常。
- 索引任务：空闲、进行中、失败。
- LLM Provider：可用、不可用、配置缺失。
- 后台任务：任务数、失败数。
- 当前模型：聊天模型、Embedding 模型。

状态必须来自主进程或 Service Manager，Renderer 不自行推断服务是否可用。

## 设置入口

设置页面按类别组织：

- 常规：启动行为、窗口行为、主题、语言、快捷键。
- 路径：知识库路径、代码仓库根目录、音乐目录、local-intel 路径。
- 模型：LLM、Embedding、ASR、TTS Provider。
- 权限：Agent 工具权限、命令执行策略、文件访问范围。
- 服务：local-intel、本地模型服务、索引服务。
- 数据：SQLite、向量库、缓存、日志。

敏感字段不在 Renderer 长期保存。API Key 只通过主进程写入 Secrets Store。

## 任务与通知

后台任务包括：

- 知识库导入和索引。
- 代码仓库扫描。
- 情报中心更新。
- 音乐库扫描。
- Agent 工具执行。

任务状态统一进入任务中心。任务中心至少记录：

- 任务类型。
- 来源页面。
- 开始时间和结束时间。
- 当前阶段。
- 进度百分比。
- 成功、失败或取消。
- 错误摘要和详细日志入口。

通知只展示结果摘要，详细信息进入任务日志。

## 空状态与错误状态

每个页面都需要定义空状态：

- 未配置路径。
- 没有导入数据。
- 服务未启动。
- Provider 未配置。
- 索引为空。

错误状态需要给出下一步动作：

- 重试。
- 打开设置。
- 查看日志。
- 跳转诊断。
- 复制错误摘要。

错误文案不暴露完整 API Key、Token 或敏感路径。

## 第一阶段验收口径

- 能说明 8 个一级页面如何注册到 Page Registry。
- 能说明默认快捷键和可重映射策略。
- 能说明页面切换器如何出现、选择、确认和关闭。
- 能说明主窗口默认只显示当前页面内容。
- 能说明页面切换后如何保留状态。
- 能说明全局状态、任务中心、设置和命令面板从哪里进入。
