# 02 页面与功能清单

## 页面总览

第一版桌面控制台包含 8 个页面入口：

- Home Dashboard
- Agent Chat
- Knowledge Base
- Agent Management
- Code Repository
- Local Music
- 情报中心
- 其他小组件

## Home Dashboard

目标：作为客户端首页，展示个人工作台的整体状态和今日入口。

核心功能：

- 今日情报摘要。
- 最近打开的代码仓库。
- 知识库索引状态。
- Agent 任务状态和最近对话。
- 本地服务健康状态。
- 音乐播放状态和快捷控制。
- 常用小组件入口。

依赖能力：

- App State Store
- local-intel 状态摘要
- Code Repository 最近项目
- Knowledge Base 索引状态
- Agent Runtime 任务日志
- Music Service 播放状态

第一版边界：只定义信息架构和数据来源，不设计精细视觉稿。

## Agent Chat

目标：提供统一对话入口，让用户通过 LLM 和工具调用操作知识库、代码仓库、情报中心和本地能力。

核心功能：

- 多会话聊天。
- 模型选择。
- 上下文来源选择。
- 工具调用记录。
- 任务执行进度。
- 引用来源展示。
- 结果保存到知识库或任务日志。

依赖能力：

- LLM Provider Adapter
- Agent Runtime
- Tool Registry
- Permission Gate
- Knowledge Search
- Code Repository Search
- Intel Query Adapter

第一版边界：先设计单用户本地 Agent，不设计复杂多用户协作。

## Knowledge Base

目标：管理个人知识资料，并支持基于来源的检索和问答。

核心功能：

- Markdown、PDF、网页剪藏导入。
- Obsidian Vault 导入和导出。
- 标签、目录和关系查看。
- 文本抽取和分块。
- 关键词索引。
- Embedding 和向量索引。
- Hybrid Search。
- RAG 问答和来源引用。

依赖能力：

- File Importer
- Text Parser
- Chunker
- Keyword Index
- Embedding Service
- Vector Store
- LLM Provider Adapter

第一版边界：重点设计数据流和模块边界，不限定具体向量数据库实现。

## Agent Management

目标：管理 Agent 的配置、权限、模型和执行历史。

核心功能：

- Agent 列表。
- Prompt 配置。
- 模型配置。
- 工具权限。
- 记忆和上下文策略。
- 任务模板。
- 执行历史和错误记录。

依赖能力：

- Agent Runtime
- Tool Registry
- LLM Provider Registry
- App SQLite
- Secrets Store

第一版边界：作为配置和监控中心，不承载主要聊天体验。

## Code Repository

目标：可视化和管理本地代码仓库，让项目结构、Git 状态和代码语义更容易理解。

核心功能：

- 本地仓库列表。
- Git 状态、分支、提交、diff。
- 文件树和忽略规则。
- 代码搜索。
- Tree-sitter 结构解析。
- 依赖图和模块图。
- 语言统计和复杂度摘要。
- 代码问答。
- PlantUML 或 Mermaid 图输出。

依赖能力：

- Git CLI Adapter
- File Walker
- ripgrep Adapter
- Tree-sitter Parser
- Dependency Analyzer
- Code Index
- LLM Code Assistant

第一版边界：先设计本地仓库读取和分析，不设计远程托管平台管理。

## 情报中心

目标：把现有 local-intel 作为独立本地服务接入桌面控制台。

核心功能：

- 启动、停止、重启 local-intel。
- 服务健康检查。
- 今日情报查看。
- 观察雷达查看。
- 来源状态查看。
- 配置入口。
- 报告文件查看。
- 调度器状态查看。

依赖能力：

- Electron Service Manager
- local-intel Python Service
- local-intel SQLite
- reports 目录
- scheduler 状态
- health check endpoint 或本地状态脚本

第一版边界：复用已有服务，不重写抓取、摘要、翻译和观察雷达逻辑。

## Local Music

目标：提供本地音乐播放和音乐库管理入口。

核心功能：

- 本地音乐目录扫描。
- 元数据读取。
- 播放、暂停、上一首、下一首。
- 播放队列。
- 收藏和播放列表。
- 歌词和封面扩展。
- 与语音助手轻量联动。

依赖能力：

- Music Library Scanner
- Audio Playback Adapter
- Metadata Scanner
- Playlist Store
- App SQLite

第一版边界：先定义播放器和音乐库模型，不把它作为主线模块。

## 其他小组件

目标：作为长期扩展入口，承载轻量个人工具。

候选功能：

- 便签。
- 计时器。
- 日程。
- 系统状态。
- 剪贴板。
- 快速命令。
- 文件收藏夹。

第一版边界：只保留入口和扩展机制，不展开具体交互。
