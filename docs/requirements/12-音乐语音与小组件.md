# 12 音乐、语音与小组件

## 目标

Local Music、Voice Assistant 和 Widgets 是桌面控制台的扩展体验层。它们不阻塞第一阶段核心工作流，但需要在架构中预留清晰入口，避免后续硬塞进 Agent 或 Dashboard。

## Local Music

### 职责

Local Music 管理本地音乐文件和播放体验。

核心能力：

- 添加音乐目录。
- 扫描音频文件。
- 读取标题、艺术家、专辑、时长、封面等元数据。
- 播放、暂停、上一首、下一首。
- 播放队列。
- 收藏。
- 播放列表。
- 搜索本地音乐。

### 存储

App SQLite 保存：

- 曲目元数据。
- 播放列表。
- 收藏状态。
- 最近播放。
- 音乐目录引用。

文件系统保存真实音乐文件。应用不复制音乐文件。

### 与 Agent 的关系

Agent 可用只读或低风险工具：

- `music.search`
- `music.play`
- `music.pause`
- `music.getPlaybackState`
- `music.addToPlaylist`

删除文件、移动文件、批量改名属于高风险操作，不纳入第一阶段默认工具。

## Voice Assistant

### 职责

Voice Assistant 负责把语音输入、语音播报和 Agent Chat 连接起来。

候选能力：

- ASR：语音转文字。
- TTS：文字转语音。
- 语音命令。
- 当前页面上下文感知。
- 与音乐播放控制联动。

### 接入边界

Voice Service 不直接执行本地操作。语音识别出的命令进入 Agent Runtime 或命令路由，再经过权限检查。

流程：

```text
麦克风输入
  -> ASR
  -> 文本命令
  -> Agent Runtime / Command Router
  -> Permission Gate
  -> 工具执行
  -> TTS 可选播报
```

### 风险

- 麦克风权限。
- 误触发命令。
- 隐私内容进入 Provider。
- 语音命令执行高风险工具。

第一阶段只定义接口和边界，不把语音作为主路径。

## 小组件

小组件是轻量工具集合。建议以 Widget Runtime 管理。

候选小组件：

- 便签。
- 计时器。
- 日程。
- 剪贴板。
- 快速命令。
- 系统状态。
- 文件收藏。
- 今日任务。

Widget Runtime 职责：

- 注册小组件。
- 管理小组件配置。
- 提供 Dashboard 卡片。
- 控制小组件权限。

小组件不能绕过 `window.api.*` 访问本地能力。

## 第一阶段验收口径

- Local Music 有明确的数据和播放边界。
- Voice Assistant 有 ASR/TTS/命令路由边界。
- 小组件有统一扩展入口。
- 三者不干扰第一阶段核心模块。
