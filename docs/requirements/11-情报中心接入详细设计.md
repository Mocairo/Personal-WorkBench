# 11 情报中心接入详细设计

## 目标

情报中心模块接入现有 `D:\python_code\local-intel\.worktrees\reliability-foundation`。Electron 不重写 local-intel，而是作为桌面入口管理服务生命周期、展示数据、打开配置和聚合状态。

## 现有能力摘要

local-intel 已具备：

- GitHub Trending。
- GitHub Releases。
- arXiv。
- Hacker News。
- GDELT。
- RSS。
- 本地评分和分类。
- LLM 摘要。
- 中文翻译。
- 事件主线聚合。
- 观察雷达。
- SQLite 数据库存储。
- 本地网页仪表盘。
- 调度器。
- 配置中心。
- 诊断脚本。

## 接入模式

Electron 通过 Service Manager 管理 local-intel：

- 启动：调用 `start_local_intel.ps1`。
- 停止：调用 `stop_local_intel.ps1`。
- 状态：调用 `status_local_intel.ps1` 或访问本地健康状态。
- 数据：读取 local-intel SQLite、reports 或本地网页/API。
- 配置：打开 local-intel 配置入口或配置文件。

## 页面能力

情报中心页面包含：

- 服务状态卡片。
- 今日情报摘要。
- 观察雷达。
- 来源健康。
- 最近报告。
- 调度器状态。
- 手动更新按钮。
- 配置入口。
- 日志入口。

Home Dashboard 只展示摘要，不承载完整情报分析。

## 数据读取边界

Electron 可以读取：

- 最近运行状态。
- 今日重点条目。
- 观察雷达摘要。
- 来源健康摘要。
- 报告列表。
- 报告文件。
- 调度器状态。

Electron 不接管：

- 抓取逻辑。
- 摘要逻辑。
- 翻译逻辑。
- 观察雷达判断逻辑。
- local-intel 原始数据库 schema 演进。

## 服务生命周期

状态定义：

- `not_configured`：路径未配置或脚本不存在。
- `stopped`：服务未运行。
- `starting`：启动中。
- `running`：网页或状态检查可用。
- `degraded`：部分能力异常，例如调度器未运行。
- `error`：启动失败或状态检查失败。

状态展示要包括：

- local-intel 路径。
- web 地址。
- web 进程状态。
- scheduler 状态。
- 上次运行时间。
- 下次运行时间。
- 最近错误摘要。

## 手动更新

手动更新应该作为后台任务：

1. 用户点击更新。
2. Electron 创建任务。
3. Service Manager 调用 local-intel pipeline 或已有脚本。
4. 任务中心展示进度。
5. 完成后刷新摘要。

如果 local-intel 已在运行更新，Electron 应提示已有任务，而不是并发启动多个抓取任务。

## 与 Agent 的关系

Agent 可用情报工具：

- `intel.getTodaySummary`
- `intel.searchItems`
- `intel.getWatchRadar`
- `intel.getSourceHealth`
- `intel.openReport`
- `intel.runUpdate`

只读工具默认可用；手动更新属于服务操作，需要权限策略允许。

## 错误处理

错误场景：

- local-intel 路径不存在。
- 脚本不存在。
- Python 环境不可用。
- 端口被占用。
- SQLite 不存在。
- 抓取失败。
- LLM API 失败。
- 调度器异常。

处理方式：

- 显示错误摘要。
- 提供查看日志入口。
- 提供重新检测路径。
- 提供运行诊断入口。
- 不把 `.env` 的敏感值显示给 Renderer。

## 第一阶段验收口径

- local-intel 作为独立服务接入。
- 启动、停止、状态、报告、配置入口职责明确。
- Electron 不重写 local-intel 业务逻辑。
- Agent 调用情报能力有权限边界。
